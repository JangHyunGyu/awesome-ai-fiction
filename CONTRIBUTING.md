# Contributing

Thanks for helping keep this list accurate. The bar is deliberately high: a short, correct list is worth more than a long, stale one.

## Inclusion criteria

An entry must meet **all** of the following:

1. **Shipped and reachable.** The official link works today and the product is usable now — not a waitlist, teaser page, or "coming soon".
2. **Fiction-relevant.** The tool's primary use is fiction: story continuation, novel writing, roleplay/character chat, companions, fiction TTS, character-card tooling, or fiction-specific evaluation. General-purpose chatbots and marketing-copy tools are out of scope.
3. **One verifiable fact.** Every description must contain at least one fact a reader can check on the linked page: pricing model, platform, open-source license, or core mechanism. No "powerful", "amazing", "best-in-class".
4. **Official link only.** Link the project's own site or source repository, never a review blog or app-store mirror (app-store pages are acceptable only when the product has no website).
5. **Neutral wording.** Entries are ordered alphabetically within each category and are never bolded or pinned. This applies to everyone, including tools made by this list's maintainers.

## Status tags

Services die quietly in this space. Instead of silently deleting an entry, first tag it:

- `status: discontinued` — official shutdown notice or dead product.
- `status: unstable` — repeated outages, data-loss incidents, or store removals within the past year.

Entries tagged `discontinued` are removed after the next verification pass.

## Affiliation disclosure

If you submit a tool you built or work on, say so in the PR description. Affiliated entries are welcome under the exact same criteria — the disclosure just gets recorded in the PR history.

## PR checklist

- [ ] Link verified reachable on the day of the PR (say how: browser / curl).
- [ ] Description ≤ 2 sentences, contains one verifiable fact, no superlatives.
- [ ] Entry inserted in alphabetical order in the right category, in **both** `README.md` and `README.zh.md`.
- [ ] The Chinese description is written natively, not machine-translated.
- [ ] Affiliation disclosed if any.

## Removal PRs are welcome

If you find a dead link, a shut-down service, or a claim that no longer matches the official page, a removal/status PR is just as valuable as an addition.
